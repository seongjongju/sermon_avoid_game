# 잔소리 피하기 게임

하늘에서 떨어지는 잔소리를 피하는 캐주얼 웹 게임입니다.

- 배포: https://sermon-avoid-game.vercel.app / https://seongjongju.itch.io/sermon-avoid-game
- GitHub: https://github.com/seongjongju/sermon_avoid_game

## 프로젝트 소개

요즘 개발자에게 AI 활용 능력이 점점 중요해지고 있다고 느꼈습니다. 그래서 AI를 실제 개발 과정에 붙여서 프로젝트 하나를 끝까지 완성해보고 싶었고, 부담 없이 끝낼 수 있도록 가벼운 게임을 주제로 잡았습니다.

개인 프로젝트이고, 개발 기간은 1개월 이내입니다. 특정 게임이나 서비스를 참고하지는 않았고, 아이디어는 "부모님이나 친척들이 하는 잔소리를 피한다"는 단순한 컨셉에서 시작했습니다.

## 게임 플레이 방식

- 화면의 시작 버튼을 마우스로 클릭하면 게임이 시작됩니다.
- 잔소리 문구가 적힌 사각형 박스가 장애물로 하늘에서 떨어집니다.
- 장애물이 플레이어를 그대로 지나치면 점수가 올라가고, 부딪히면 게임이 종료됩니다.
- 별도의 제한 시간은 없습니다.
- 게임 오버 화면에는 재시작 버튼이 뜹니다.
- 효과음은 없지만 BGM이 있고, 음소거와 볼륨 조절이 가능합니다.

## 기술 스택

- React
- Vite
- SCSS

React를 선택한 이유는 렌더링 방식 때문입니다. 하늘에서 떨어지는 장애물은 랜덤 값으로 계속 생성되는데, 이걸 바닐라 자바스크립트로 처리하면 매번 불필요한 렌더링이 많이 일어나 성능이 떨어집니다. 그래서 useRef로 상태를 관리하면서 실제로 감지가 필요한 시점에만 렌더링이 일어나도록 구성했습니다.

Vite는 빠른 번들링 속도 때문에 선택했습니다. SCSS는 강한 이유는 없지만, 중첩 문법 덕분에 스타일 구조를 파악하기 편했고 문법도 styled-components와 비슷해서 익숙하게 사용했습니다.

## 구현된 핵심 요소

- 상태 관리 (useState / useRef)
- 장애물과 플레이어 간 충돌 판정
- 키보드 및 마우스 이벤트 처리
- BGM 재생, 음소거 및 볼륨 조절 로직

코드 작성 자체는 아래 "AI와 함께 작업한 방식"에 설명한 방식으로 진행했습니다.

## AI와 함께 작업한 방식

이 프로젝트에서 가장 보여주고 싶은 부분은 AI를 실제 작업 도구로 다뤄본 경험입니다.

작업 방식은 이렇습니다. 먼저 ChatGPT로 요구사항을 프롬프트로 정리하고, 그 내용을 제가 직접 검토합니다. 검토가 끝나면 Gemini에게 실제 코드 작성과 그래픽 작업을 요청합니다. 결과물이 나오면 다시 제가 검수하고, 수정이 필요하면 코드를 직접 고치는 대신 Gemini에게 다시 요청해서 반영했습니다.

그래픽 리소스도 같은 방식으로 Gemini를 활용해서 만들었습니다.

정리하면, 코드 작성과 디버깅은 AI가 담당했고, 저는 요구사항 정의와 결과물 검수, 방향 결정을 맡았습니다. 이 구분은 README에서도 그대로 밝히려고 합니다.

## 아쉬운 점
